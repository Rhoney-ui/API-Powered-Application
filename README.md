# API-Powered-Application
Shows a 3 day weather forecast for any city using the OpenWeatherMap API.

## Setup

1. Clone the repo
2. Run: pip install requests python-dotenv
3. Create a .env file with: OPENWEATHER_API_KEY=your_key_here
4. Get a free key at openweathermap.org

## Usage

python weather.py

## Example Output
Enter a city: Nairobi
Weather in Nairobi: 22C, partly cloudy, humidity 65%
